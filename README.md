### Привет!

Структура:

| Пакет        | Назначение                                                           | Файл                         | Назначение файла                                                                                    |
|--------------|----------------------------------------------------------------------|------------------------------|-----------------------------------------------------------------------------------------------------|
| api_frame    | Обертка над requests                                                 | base_api                     | Стандартная обертка над requests, взято с хабра                                                     |
|              |                                                                      | endpoints                    | Все URl'ы нужные хранятся тут                                                                       |
|              |                                                                      | create_operator              | Класс для отправки POST'а по нужному url                                                            |
|              |                                                                      | get_operators                | Класс для отправки GET'а по нужному url                                                             |
|              |                                                                      | get_countries                | Класс для получения данных по странам (нужен для countryId для отправки POST'а для create_operator) |
| assertions   | Пакет с тестами и ассертами (разбито на два пакета: 01_post, 02_get) | conftest                     | Фикстуры                                                                                            |
|              |                                                                      | assertions.py                | функции с ассертами для контрактной проверки                                                        |
|              |                                                                      | 01_create/test_post_operator | Тест для POST операторов                                                                            |
|              |                                                                      | 02_get/test_get_operators    | Тест для GET операторов                                                                             |
| dict_payload | Пакет с JSON сообщениями для отправки данных                         | conftest                     | Фикстуры (да, я знаю, что это мусорно, несколько conftest'ов, но я пока не разобрался на 100%)      |
|              |                                                                      | payload_create_oper          | payload для отправки данных по операторам                                                           |
| tools        | Пакет с хелперами                                                    | conftest                     | опять фикстуры                                                                                      |
|              |                                                                      | get_country_id               | функция для определения ID страны, который получается в ответе GET countries                        |
| --           | .gitignore                                                           | .gitignore                   | Гитигнор, ничего необычного                                                                         |
| --           | run.sh                                                               | run.sh                       | Моя попытка упорядочить вызов тестов (сначала POST, потом GET)                                      |
|              |                                                                      |                              |                                                                                                     |
| --           | .env                                                                 | .env                         | Тут хранится адрес, в гитигноре настроен для игнора                                                 |
